## About

I am an applied cryptographer and security engineer in Berlin. I have worked in industry since 2019.

At **ITK Engineering (Bosch Group)** I do threat modeling, security code review and cryptographic integration for embedded systems. At **EAGLYS** in Tokyo I built homomorphic encryption and MPC for a database that runs SQL on encrypted data. My **Ph.D.** was on fast pairing computation over elliptic curves.

## What I do

- **Security review.** Threat modeling and risk assessment (ISO/SAE 21434 TARA). Security code review of C and C++. Secure coding guidelines based on SEI CERT.
- **Cryptographic engineering.** Pairings and elliptic curve arithmetic, multi-scalar multiplication, homomorphic encryption, MPC and attribute-based encryption. I implement them from scratch in C, C++ and Rust, and I make them fast: 17x faster encryption and decryption at EAGLYS.
- **Security process.** EU Cyber Resilience Act readiness, SBOM and vulnerability disclosure.
